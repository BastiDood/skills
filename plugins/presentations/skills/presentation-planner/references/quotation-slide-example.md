# Presenter-Led Quotation Slide

<original_verbatim_text>

The first and foremost myth that I want to dispel is the claim that "CS is now a dying field." This dangerous rhetoric is only amplified by AI tech bros and CEOs, especially when Dario Amodei (CEO of Anthropic) himself says things like:

> _"I think coding is going away first, or coding is being done by the AI models first, and then the broader task of software engineering will take longer."_

Notably, he predicts that coding itself will disappear.

</original_verbatim_text>

<anti_example>

Title: "CS Is Now a Dying Field"

- The claim that **"CS is now a dying field."**
  - _"I think coding is going away first, or coding is being done by the AI models first, and then the broader task of software engineering will take longer."_

</anti_example>

<why_the_anti_example_fails>

The visible title and setup compete with the quotation and reduce its impact. The presenter should supply the frame aloud; the audience should see only the exact quotation on an otherwise blank canvas.

</why_the_anti_example_fails>

<rule_demonstrated>

Treat a standalone blockquote as a quotation beat. Use the working title only for plan navigation, make the quotation the sole visible content, place its setup and attribution in presenter notes, and use `[Read slide.]` only because that exact quotation appears on the same slide.

</rule_demonstrated>
