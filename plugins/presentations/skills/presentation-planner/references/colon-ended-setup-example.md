# Introduced Lists and Preserved Depth

<original_verbatim_text>

The harness injects other information like:

- The system prompt
- The MCP descriptions
  - Tool definitions
- The user messages

All you need to know is that context adds up.

</original_verbatim_text>

<expected_on_slide_content>

- The harness injects other **information** like:
  - The system prompt
  - The MCP descriptions
    - Tool definitions
  - The user messages

</expected_on_slide_content>

- The harness injects other information like:

  - The user messages

</expected_presenter_notes>

<rule_demonstrated>

The colon-ended setup is level 0. Its introduced list moves to level 1, and the source-authored nested item remains one level below its parent at level 2. The sentence after the list is a new conclusion, so it returns to level 0. Do not flatten source list depth or keep later independent prose trapped under the setup.

</rule_demonstrated>
