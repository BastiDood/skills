# Lowercase Technical Identifier

<original_verbatim_text>

tokio::spawn creates a task. The task can run concurrently.

</original_verbatim_text>

<expected_on_slide_content>

- **tokio::spawn**
  - Concurrent task

</expected_on_slide_content>

<expected_presenter_notes>

- tokio::spawn creates a task.
  - The task can run concurrently.

</expected_presenter_notes>

<anti_example>

- **Tokio::Spawn** creates a task.
  - The task can run concurrently.

</anti_example>

<why_the_anti_example_fails>

It normalizes a literal identifier and copies both note sentences when two compact labels carry the visual job.

</why_the_anti_example_fails>

<rule_demonstrated>

Preserve a lowercase literal identifier while compressing the surrounding prose; nesting does not license case normalization.

</rule_demonstrated>
