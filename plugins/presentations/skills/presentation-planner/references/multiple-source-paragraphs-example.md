# Multiple Source Paragraphs

<original_verbatim_text>

Context windows are finite. Each message consumes part of the available space.

Compaction preserves the gist. It cannot preserve every detail.

The practical rule is simple. Start a fresh conversation for each new task.

</original_verbatim_text>

<expected_on_slide_content>

One-slide treatment when the three paragraphs form one cumulative beat:

- The practical rule is simple.
  - Start a **fresh conversation** for each new task.

Two-slide treatment when the final rule is a new audience task or the first slide reaches its pacing limit:

Slide 1:

- **Context windows** are finite.

Slide 2:

- The practical rule is simple.
  - Start a **fresh conversation** for each new task.

</expected_on_slide_content>

<expected_presenter_notes>

One-slide treatment:

- Context windows are finite.
  - Each message consumes part of the available space.
- Compaction preserves the gist.
  - It cannot preserve every detail.
- The practical rule is simple.
  - Start a fresh conversation for each new task.

Two-slide treatment:

Slide 1:

- Context windows are finite.
  - Each message consumes part of the available space.
- Compaction preserves the gist.
  - It cannot preserve every detail.
- (The practical rule is simple…)

Slide 2:

- The practical rule is simple.
  - Start a fresh conversation for each new task.

</expected_presenter_notes>

<rule_demonstrated>

Paragraph boundaries do not determine slide boundaries. Several level-0 note groups can stay together when they form one cumulative spoken beat and fit the pacing limits. Split before the final group when it changes the audience task or creates an overloaded slide. In the two-slide treatment, the outgoing notes preview the first spoken bullet of slide 2 without assigning that source span to slide 1. The final instruction remains one semantic group in either treatment. On-slide content selects the single group that best cues each slide's job; it does not reproduce every top-level note bullet.

</rule_demonstrated>
