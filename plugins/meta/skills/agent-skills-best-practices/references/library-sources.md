# Library Sources

Keep the lookup identifiers of a skill dedicated to one external library in `SKILL.md`, not in a reference. Looking up the library is part of operating the skill rather than conditional domain guidance. The identifiers therefore stay visible whenever the skill is active:

<library_sources_example>

```markdown
## Library Sources

- GitHub: `owner/repository`
- Context7: `/owner/repository`
- DeepWiki: `owner/repository`
```

</library_sources_example>

Use Context7 for current library documentation and DeepWiki when documentation is insufficient or conflicts with implementation. Verify identifiers before publishing them; never invent a missing ID.

Source identifiers make current documentation fetchable. This removes the excuse for embedding a tutorial in the skill.
